# Security

## Reporting

Report suspected vulnerabilities privately through GitHub's private vulnerability reporting or Security Advisory workflow. Do not publish exploit details, credentials, or personal data in a public issue.

## Project expectations

- Never commit secrets or tokens.
- Treat external inputs and network data as untrusted.
- Keep optional data integrations opt-in and privacy-conscious.
- Document security-sensitive assumptions and failure modes.
- Use dependencies only after their purpose, maintenance status, and license are reviewed.
