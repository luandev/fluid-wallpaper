fluid-wallpaper · Preview

Bring living fluid to your interface.

Choose a native web component or a React component. Both ship as compiled JavaScript with TypeScript declarations. No shader loader or special Vite setup is needed.

The examples on this site use the local build. Registry and CDN commands below work once version 0.1.0-next.0 is published.

Install

npm install fluid-wallpaper@next
# Yarn works too:
yarn add fluid-wallpaper@next

Web component

No React dependency or external CSS. Give the host a height.

import { defineFluidInk } from 'fluid-wallpaper/element';
defineFluidInk();

// Add to your HTML:
<fluid-ink quality="eco" style="height:360px">
  <p slot="fallback">This artwork needs WebGL2.</p>
</fluid-ink>

React 19

npm install react@^19 react-dom@^19

import { FluidField } from 'fluid-wallpaper/react';
import 'fluid-wallpaper/styles.css';

export function Artwork() {
  return <div style={{ height: 360 }}>
    <FluidField config={{ vorticity: 12 }} onError={console.error} />
  </div>;
}

For the artist panel, add dashboard. Persistence defaults off. Configuration is applied on mount; use onEngine and engine.applyConfig() for later changes. Resolution changes also need engine.reseed().

Control the element

import type { FluidInkElement } from 'fluid-wallpaper/element';
const field = document.querySelector('fluid-ink') as FluidInkElement;
field.addEventListener('ready', () => {
  field.setConfig({ vorticity: 18 });
  field.pause();
  field.play();
  field.inject({ position: { x: 0.5, y: 0.5 }, velocity: { x: 0.1, y: 0 } });
});
field.addEventListener('error', event => console.error(event));

Set paused before insertion for an initially paused field. reset() recreates the composition. The element also emits configchange and qualitychange.

Experimental liquids

import { defineFluidInk, defaultLiquidScene } from 'fluid-wallpaper/element';
defineFluidInk();
const field = document.createElement('fluid-ink');
field.setAttribute('paused', '');
field.style.height = '320px';
// In TypeScript, cast field to FluidInkElement.
field.scene = defaultLiquidScene();
document.body.append(field);

The two-liquid scene is available through the element; React keeps the established material solver. Open the experimental studio.

Before shipping your integration

Mount only in the browser. In server-component frameworks, put React artwork behind a client boundary and import the stylesheet through the framework's supported CSS entry. Modules may be imported without a DOM; constructing an element requires one.

WebGL2 and floating-point render targets are required. Mobile performance and two-liquid accuracy are not certified. Dashboard presets and panel positions can share browser storage even when base-config persistence is off.
