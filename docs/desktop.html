fluid-wallpaper / Desktop

One HTML pack.
Three desktops.

Offline WebGL2 wallpaper for Wallpaper Engine, Lively, and Mac HTML hosts — minimal zip, no Workshop properties yet.

Open wallpaper entryHow the fluid works ↗

Build with yarn pack:wallpaper (or download a release zip when attached). The pack root contains wallpaper.html, assets/, Wallpaper Engine project.json, Lively LivelyInfo.json, and INSTALL.txt.

What you get

  • Full-bleed field with ECO enabled; pauses when the host hides the page
  • Optional scene: wallpaper.html?scene=aurora|obsidian|porcelain
  • Offline — no fonts CDN, YouTube, or npm required at runtime
  • Needs WebGL2 and floating-point targets; host GPU behavior is device-specific and not certified here

Windows 11 — Wallpaper Engine

  1. Open the Wallpaper Engine editor.
  2. Drag wallpaper.html onto Create Wallpaper, or import the unpacked folder.
  3. Confirm type web and apply.

Workshop upload, user properties, and audio listeners are not part of this minimal pack.

Windows 11 — Lively Wallpaper

  1. Install Lively Wallpaper.
  2. Drag the pack folder into Lively, or add wallpaper.html.
  3. Set as wallpaper.

Linux — Wallpaper Engine

Where Wallpaper Engine is available on Steam for Linux, import the same folder as on Windows (web wallpaper → wallpaper.html).

macOS — HTML wallpaper host

Wallpaper Engine is not the Mac path for this pack. Use a local HTML wallpaper host (for example Plash or ScreenPlay-class apps):

  1. Keep the folder intact (HTML + assets/).
  2. Point the host at wallpaper.html.
  3. Prefer offline/local file loading.
