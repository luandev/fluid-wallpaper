# Generative Fluid Wallpaper

A documentation-first home for a generative wallpaper that should feel fluid, material, intricate, and alive.

## Current status

Discovery and definition. This repository intentionally contains no implementation yet.

## North star

Create ambient desktop art that is interesting enough to watch deliberately and efficient enough to leave running.
