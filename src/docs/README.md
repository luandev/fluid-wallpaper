# Public docs site

Seven HTML entries under docs/ provide integration, a settings reference, hero recipes, gallery, shader/technique explainer, desktop wallpaper install, and preset contributions. Runtime heroes/presets on the public site load the **published** npm preview (`fluid-wallpaper@0.1.0-next.0`) from jsDelivr; see `published.ts`. `main.ts` still coordinates a single active hero/preview and gallery actions. Page heroes use hand-authored configs in `heroes.ts`; gallery cards apply full preset configs to both the page hero and the live preview. `reference.ts` draws defaults/help from authored config and supplements collection/experimental descriptions; missing entries throw and are covered by tests. `docs.css` owns the responsive shell.

The gallery stores selections in its URL and never persists tuner settings. Only explicit tuner edits/saves persist. Images are captured source assets; shader rendering remains in the engine. Static headings/content and fallback backgrounds remain readable without animation. Vite uses relative paths for nested Pages deployment.
