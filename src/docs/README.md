# Public docs site

Six HTML entries under docs/ provide integration, a settings reference, hero recipes, gallery, shader/technique explainer, and preset contributions. `main.ts` uses compiled package exports for heroes/presets, renders safe text from shared reference metadata, coordinates a single active hero/preview, and supplies gallery actions. Page heroes are driven by hand-authored configs in `heroes.ts`; gallery cards apply full preset configs to both the page hero and the live preview. `reference.ts` draws defaults/help from authored config and supplements collection/experimental descriptions; missing entries throw and are covered by tests. `docs.css` owns the responsive shell.

The gallery stores selections in its URL and never persists tuner settings. Only explicit tuner edits/saves persist. Images are captured source assets; shader rendering remains in the engine. Static headings/content and fallback backgrounds remain readable without animation. Vite uses relative paths for nested Pages deployment.
