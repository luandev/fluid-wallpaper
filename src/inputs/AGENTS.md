# Optional interaction: agent context

Scope: `src/inputs/` and descendants. Read [root guidance](../../AGENTS.md), ancestor instructions, and [this folder's contract](README.md).

Keep browser capture and pointer adapters independent of React and fluid appearance. Media capture requires the existing explicit user gesture path; denied/stopped capture must leave bounded silent input and release tracks/resources. Camera/tilt are stubs. Coordinate pointer changes with spatial guidance and CPU audio/UV tests where applicable.

For change recipes and known limitations, see [the engineering guide](../../docs/ENGINEERING_GUIDE.md). Follow root validation rules and update local context when a contract changes.
